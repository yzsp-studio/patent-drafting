## 🇬🇧 English

Drafts or revises Chinese invention and utility-model patent applications from a technical disclosure, and can also review an existing claim set. Before writing anything it must route the task and follow the main-flow routing table, with a red-line checklist and a delivery contract in force throughout. Patent search, FTO/infringement analysis, invalidation, office-action responses, trademarks and copyright sit in adjacent territory: when the user raises only those, this flow does not apply; when they are mixed in with a drafting request, drafting proceeds as normal but the final reply must account for every other request item by item — missing any one makes the delivery incomplete.

### ✨ What it does

- Technical disclosure in → claims and specification out
- Drafts or revises Chinese invention and utility-model applications
- Reviews an existing claim set and points out defects
- Mandatory task routing before drafting, then the main flow by the routing table
- Red-line checklist in force at all times; contract word for word, internal notes kept separate
- Adjacent requests (search/FTO/invalidation/office action/trademark) are each accounted for
